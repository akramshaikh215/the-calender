# Python Monthly Calendar Generator

A simple Python program that allows users to enter a year and a month, then displays the corresponding monthly calendar using Python's built-in `calendar` module. This beginner-friendly project demonstrates user input, module import, and formatted output.

## Features

* Accepts year and month as user input.
* Displays the complete calendar for the selected month.
* Uses Python's built-in `calendar` module (no external libraries required).
* Easy to understand and ideal for beginners learning Python.

## Technologies Used

* Python 3
* Built-in `calendar` module

## Example

**Input:**

* Year: `2026`
* Month: `8`

**Output:**
Displays the complete calendar for **August 2026**.
